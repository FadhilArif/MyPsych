# Skema Database Supabase

> **Sumber:** disimpulkan dari pemakaian kolom di `api/gateway.js` dan
> `src/features/**`. Tidak ada file migrasi di repo, jadi dokumen ini adalah
> hasil pembacaan kode — **verifikasi ke dashboard Supabase** sebelum dipakai
> untuk membangun ulang environment.
>
> Nama tabel dan kolom mengikuti apa adanya di kode, termasuk yang memakai
> tanda hubung (`"user-id"`) sehingga **wajib dikutip** di SQL.

## Daftar tabel

| Tabel | Fungsi | Akses |
|---|---|---|
| `table_user` | akun peserta & admin | service role (server) |
| `test_history` | ringkasan hasil per tes | server |
| `test_detail` | jawaban per soal | server |
| `question_bank` | bank soal + kunci jawaban | server |
| `score_labels` | label interpretasi skor per jenis tes | server |
| `pdf_downloads` | log unduhan PDF | server |
| `revoked_tokens` | daftar sesi yang di-logout | server |
| `admin_audit_log` | jejak aksi admin | server |
| `interest_signups` | daftar tunggu fitur baru | server |

Semua akses lewat `SUPABASE_SERVICE_ROLE_KEY`, yang **melewati Row Level
Security**. Karena itu RLS sebaiknya tetap diaktifkan dengan **nol policy
untuk anon/authenticated**, sehingga kunci service-role satu-satunya jalan
masuk.

## DDL referensi

```sql
-- ============================================================
-- AKUN
-- ============================================================
create table if not exists table_user (
  "user-id"                 text primary key,          -- format U00001
  username                  text not null,
  email                     text not null,
  password_hash             text not null,             -- bcrypt ($2a/$2b/$2y) atau SHA-256 legacy
  salt                      text default '',           -- hanya untuk hash legacy
  role                      text not null default 'user', -- 'user' | 'admin'
  created_at                timestamptz not null default now(),

  -- alur reset password
  reset_token               text,
  reset_token_expires       timestamptz,
  reset_requested_at        timestamptz,
  reset_request_count_today integer default 0,
  reset_request_date        text                      -- 'YYYY-MM-DD'
);

-- Cegah duplikasi & race condition saat registrasi
create unique index if not exists table_user_username_key on table_user (lower(username));
create unique index if not exists table_user_email_key    on table_user (lower(email));
create index if not exists table_user_reset_token_idx     on table_user (reset_token);

-- ============================================================
-- HASIL TES
-- ============================================================
create table if not exists test_history (
  test_id     text primary key,
  user_id     text not null references table_user ("user-id") on delete cascade,
  test_type   text not null,
  package     integer not null default 1,
  tanggal     timestamptz not null default now(),
  score       integer not null default 0,
  correct     integer not null default 0,
  wrong       integer not null default 0,
  total       integer not null default 0,
  speed       integer not null default 0,
  accuracy    integer not null default 0,
  consistency integer not null default 0,
  endurance   integer not null default 0
);

create index if not exists test_history_user_tanggal_idx
  on test_history (user_id, tanggal desc);

create table if not exists test_detail (
  id                  bigint generated by default as identity primary key,
  test_id             text not null,          -- mengacu test_history.test_id (tanpa FK di kode)
  user_id             text not null,
  test_type           text not null,
  package             integer not null default 1,
  no_soal             integer not null default 0,
  kolom               integer,                -- khusus Kraepelin
  no_soal_dalam_kolom integer,                -- khusus Kraepelin
  waktu_detik         numeric,
  jawaban             text default '',
  benar               boolean not null default false
);

create index if not exists test_detail_test_id_idx on test_detail (test_id);
create index if not exists test_detail_user_idx    on test_detail (user_id);

-- ============================================================
-- BANK SOAL
-- ============================================================
create table if not exists question_bank (
  question_id text primary key,
  test_type   text not null,
  package     integer not null default 1,
  no_soal     integer not null default 1,
  question    text not null,
  option_a    text,
  option_b    text,
  option_c    text,
  option_d    text,
  option_e    text,
  answer      text not null,          -- huruf opsi benar: A..E
  discussion  text default '',        -- pembahasan
  active      boolean not null default true
);

create index if not exists question_bank_lookup_idx
  on question_bank (test_type, package, no_soal);

-- ============================================================
-- LAIN-LAIN
-- ============================================================
create table if not exists score_labels (
  id        bigint generated by default as identity primary key,
  test_type text not null,
  label     text not null,
  min_score integer not null default 0,
  max_score integer not null default 100,
  urutan    integer not null default 1
);

create table if not exists pdf_downloads (
  id         bigint generated by default as identity primary key,
  test_id    text not null,
  user_id    text,                     -- null = tamu
  created_at timestamptz not null default now()
);

create unique index if not exists pdf_downloads_test_user_key
  on pdf_downloads (test_id, user_id) where user_id is not null;

create table if not exists revoked_tokens (
  id         bigint generated by default as identity primary key,
  token_hash text not null unique,     -- SHA-256 dari JWT
  user_id    text,
  reason     text default '',
  revoked_at timestamptz not null default now(),
  expires_at timestamptz not null default now()
);

create index if not exists revoked_tokens_hash_idx on revoked_tokens (token_hash);

create table if not exists admin_audit_log (
  id             bigint generated by default as identity primary key,
  admin_user_id  text not null,
  admin_username text default '',
  action         text not null,
  target_id      text default '',
  target_label   text default '',
  success        boolean not null default true,
  message        text default '',
  created_at     timestamptz not null default now()
);

create index if not exists admin_audit_log_created_idx
  on admin_audit_log (created_at desc);

create table if not exists interest_signups (
  id         bigint generated by default as identity primary key,
  email      text not null,
  category   text not null,
  user_id    text,
  note       text default '',
  status     text not null default 'pending',
  created_at timestamptz not null default now()
);

create unique index if not exists interest_signups_email_category_key
  on interest_signups (email, category);
```

## Catatan operasional

- **`test_id` di `test_detail` tidak punya foreign key** di kode; integritas
  dijaga manual (insert detail hanya untuk `test_id` milik user yang sama).
- **Pembersihan `revoked_tokens`** belum otomatis. Tambahkan pg_cron:

  ```sql
  select cron.schedule('purge-revoked-tokens', '0 * * * *',
    $$ delete from revoked_tokens where expires_at < now() $$);
  ```

- **`table_user."user-id"`** memakai format `U` + 5 digit. Nilai baru dihitung
  dari ID maksimum yang ada, jadi tabel ini tidak boleh diisi paralel tanpa
  unique constraint.
