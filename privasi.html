Kebijakan Privasi

Berlaku sejak:13 September 2026 · Terakhir diubah: 13 September 2026

MyPsych ("kami") menghargai privasi kamu. Dokumen ini menjelaskan data apa yang kami kumpulkan, bagaimana kami menggunakannya, dan hak-hak kamu sebagai pengguna.

1. Data yang Kami Kumpulkan

a. Data yang kamu berikan langsung

  • Username — untuk identifikasi akun
  • Alamat email — untuk reset password dan komunikasi penting
  • Password — disimpan dalam bentuk hash (bcrypt), tidak pernah dalam bentuk asli

b. Data yang dihasilkan saat menggunakan layanan

  • Hasil tes — skor, kecepatan, ketelitian, konsistensi, ketahanan
  • Detail jawaban — jawaban per soal, waktu per soal
  • Waktu pengerjaan — timestamp kapan kamu mengerjakan tes

c. Data teknis

  • Alamat IP — untuk mencegah penyalahgunaan (rate limiting)
  • User agent browser — untuk kompatibilitas
  • Log audit — untuk keamanan sistem

2. Bagaimana Kami Menggunakan Data

  • Menampilkan hasil tes dan histori latihanmu
  • Menghasilkan laporan PDF
  • Mengirim email reset password kalau kamu memintanya
  • Melindungi sistem dari penyalahgunaan (rate limit, anti-spam)
  • Memperbaiki layanan secara umum (statistik anonim)

Kami tidak menggunakan data untuk:

  • Iklan atau profiling komersial
  • Menjual atau menyewakan ke pihak ketiga
  • Pelatihan model AI publik

3. Di Mana Data Disimpan

Data disimpan di infrastruktur cloud pihak ketiga yang terpercaya:

  • Supabase (database utama) — enkripsi at-rest
  • Vercel (backend) — HTTPS, enkripsi transit
  • Google Apps Script (pengiriman email) — HANYA menerima email + template, tidak menyimpan data

4. Berapa Lama Data Disimpan

  • Data akun — selama akun aktif
  • Hasil tes — selama akun aktif
  • Log audit — maksimal 90 hari
  • Token reset password — 30 menit atau sampai digunakan

Kalau kamu menghapus akun, kami akan menghapus semua data terkait dalam waktu maksimal 30 hari.

5. Hak Kamu

Sesuai UU Perlindungan Data Pribadi (UU PDP) Indonesia dan GDPR untuk pengguna Eropa:

  • Hak akses — melihat data yang kami simpan tentangmu
  • Hak koreksi — memperbaiki data yang salah
  • Hak hapus — meminta penghapusan akun dan seluruh data
  • Hak ekspor — meminta salinan data dalam format terbuka (JSON)

Untuk menggunakan hak-hak ini, hubungi kami di psikotesbyfadhil@gmail.com.

6. Keamanan

Kami menerapkan praktik keamanan berikut:

  • Password di-hash dengan bcrypt (standar industri)
  • Koneksi terenkripsi HTTPS end-to-end
  • Rate limiting untuk mencegah brute force dan spam
  • Audit log untuk aksi administratif
  • Row Level Security di database

Meski begitu, tidak ada sistem yang 100% aman. Kalau ada indikasi kebocoran data, kami akan menginformasikan ke pengguna dalam waktu 72 jam.

7. Cookie dan Storage

Kami menggunakan:

  • LocalStorage — untuk menyimpan sesi login di browser kamu
  • Tidak ada cookie tracking pihak ketiga
  • Tidak ada Google Analytics / Facebook Pixel

Kamu bisa menghapus data lokal kapan saja lewat pengaturan browser. Efek: kamu akan otomatis logout.

8. Anak di Bawah Umur

MyPsych tidak ditujukan untuk anak di bawah 13 tahun. Kalau kamu orang tua dan tahu anakmu mendaftar tanpa izin, hubungi kami untuk menghapus akun.

9. Perubahan Kebijakan

Kami dapat mengubah kebijakan ini dari waktu ke waktu. Perubahan signifikan akan kami beritahu lewat email terdaftar.
